# 系統色蠟筆輪廓票券

使用系統藍 #02569b、暖黃 #f8b003、墨黑 #020d15、紙白 #fdfcf8 與暖白背景 #f8f0e3。平塗材質、細微不規則輪廓模擬蠟筆毛邊；四角以平面幾何建立圓角，不受薄紙厚度限制。內側半圓拉耳與封條一起翻開，底下保留同形白紙。

保留先前要求：無文字、無裝飾圖案。參考第二張的開啟結構，背面為墨黑空白。

- `ichiban-crayon.blend` / `ichiban-crayon.glb`：未撕起始，20 段翻折形變與示範動畫。
- `create_scene.py`：以 Blender --background --python 執行重建。

模型已接入一番賞 3D 輪播與撕籤互動。毛邊為幾何輪廓，不是紙紋貼圖。GLB 不包含棚景、攝影機或燈光。
