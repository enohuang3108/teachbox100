# 感官與投影補充人工觀察

- 執行時間：2026-09-27（Asia/Taipei）
- 目標：`http://127.0.0.1:3199`，本機 production build
- 瀏覽器：獨立 Chromium browser context；桌機 1440 × 900、手機模擬 390 × 844（`hasTouch`、`isMobile`）
- 以下只記錄實際瀏覽器操作與可見結果，案例判決由主 QA 報告處理。手機觸控是 Chromium 模擬事件；音效與投影遠距離可讀性沒有真人／實體裝置驗證。

## CLOCK-003 老師拖曳指針與滑桿設定題目時間

桌機從介紹頁進入設定，再開始作答。初始題目滑桿為 `147` 分，右側作答保持 `00:00`。以滑鼠從分針的可點擊像素拖到鐘面右側，分針角度由 `162°` 變為 `90°`，題目滑桿由 `147` 變為 `135` 分；右側作答仍是 `00:00`。接著拖曳時針可點擊像素，時針角度及滑桿值均沒有改變。時針不能單獨拖動，與 case 步驟「拖曳時針、分針」的字面要求不同。點滑桿軌道後，題目改為 `24` 分，再用滑桿鍵盤 `Home` 設為 `0` 分；時針／分針回到 12 點、右側作答仍是 `00:00`，按「確定」顯示「完全正確」。

手機模擬從介紹頁進入作答。使用 Chrome DevTools `Input.dispatchTouchEvent` 在滑桿拇指上開始觸控，移到軌道左端後放開。題目滑桿由 `528` 變為 `24` 分，指針同步變動，右側作答仍是 `00:00`；再用鍵盤 `Home` 將題目設為 `0` 分，按「確定」顯示「完全正確」。這證明模擬觸控滑桿事件會改題目；真機觸控手感尚未驗證。兩個 viewport 的答對畫面均已完成。

## ICHI-004 撕票音效有開關並記住

桌機與手機模擬各用新的 browser context 開局。頂列初始有「關閉音效」鈕；點後變成「開啟音效」，`aria-pressed=false`，`localStorage` 的 `ichiban-prizes.state.sound` 為 `false`。重新整理後回到介紹頁，重新按「開始使用」並通過設定，頂列仍是「開啟音效」、`aria-pressed=false`；兩個 viewport 的 localStorage 仍為 `sound:false`。

這些操作只證實開關畫面與重整後的偏好保存。瀏覽器執行環境無真人聽音，未證實關閉後撕票實際無聲，也未驗證開啟後的揭曉音效。

畫面證據：[桌機重進後關閉狀態](assets/2026-09-25-e23a7f9/ICHI-004-desktop-verified.png)、[手機模擬重進後關閉狀態](assets/2026-09-25-e23a7f9/ICHI-004-mobile-verified.png)。

## TIMER-002 倒數到 0 響鈴

桌機與手機模擬各用新的 browser context 開 `/timer`，按「開始使用」，從預設時間選單選 `01:00` 並按「開始」。兩者均實際等待完整倒數；開始時主鈕變成紅色「暫停」，到零時 `role=timer` 顯示 `00:00` 與「時間到！」，數字呈紅色（瀏覽器計算色值 `rgb(203, 33, 8)`），主鈕變「再一次」。

畫面提示已觀察到。響鈴仍需要真人在有聲音輸出的裝置上聽到，這次未確認實際聲音。

畫面證據：[桌機零點](assets/2026-09-25-e23a7f9/TIMER-002-desktop-verified.png)、[手機模擬零點](assets/2026-09-25-e23a7f9/TIMER-002-mobile-verified.png)。

## WHEEL-002 全螢幕投影下轉動與結果可讀

桌機設定名單為「小明、小華」，進入主畫面後按頂列「全螢幕」。`document.fullscreenElement.id` 變為 `game-stage`，舞台佔滿 1440 × 900；`--fs-scale` 為 `1`。舞台內層從 896 × 544 變為 1024 × 544；轉盤在全螢幕前後都為 544 × 544，故此 viewport **沒有觀察到轉盤本身放大**。按「轉動轉盤」時鈕變「轉動中」，停下後顯示「抽到了／小明」，左側紀錄新增「第 1 個／小明」。結果區在全螢幕中的邊界為 x=672–768、y=73–154，完全位於 viewport 內；畫面可從一般桌機觀看距離讀取。

這次只有桌機螢幕上的 Chromium 全螢幕，沒有實體投影機或教室觀看距離，因此無法判定投影遠處是否清楚可讀。case 原文所說「舞台等比放大」在此尺寸下只觀察到舞台擴展、轉盤尺寸維持 544 × 544。
