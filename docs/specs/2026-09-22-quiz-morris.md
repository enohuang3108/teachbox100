# 圈叉搶答規格

## 核心玩法

- 紅隊固定使用圈，藍隊固定使用叉；隊名可設定。
- 棋盤為 3 × 3，橫、直、斜任一三連線即獲勝。
- 每隊各有三枚棋。尚未放完三枚時，答對可在空格放棋；三枚都在場上後，答對可把任一己方棋移到任一空格。
- 放棋或移棋點下即生效，不提供確認或復原。

## 搶答與題目

- 只使用選擇題與是非題，至少需要六題；難度只篩選題目，不影響棋步。
- 兩隊各自取得同一份題庫的完整洗牌副本，當下顯示的題目不可相同。
- 兩隊平時可同時作答；系統先收到哪隊的正確答案，就暫停全場並讓該隊下棋。另一隊保留目前題目，棋步完成後才恢復作答。
- 答錯要顯示正解與解析，該隊冷卻三秒後才出下一題；另一隊不受影響。若進入棋步，冷卻倒數跟著暫停。
- 無一般作答時限。單隊題目用完後等待；兩隊都用完才自動和局。老師也可手動結束本局。

## 開局、結果與設定

- 兩隊各按一次準備，接著共同倒數 3、2、1，再同時出題。
- 結果畫面保留最終棋盤，勝利時標示連線，提供「再玩一次」與「設定」。
- 再玩一次會清空棋盤、重新洗題並回到兩隊準備；保留題庫、難度與隊名。
- 分享連結包含題庫、難度上限與隊名，不包含音效設定或遊戲進度。
- 提供倒數、答對、答錯、落子、獲勝音效與音效開關。
