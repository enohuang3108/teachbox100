# TeachBox100 測試矩陣

這張矩陣是行為的唯一真相：日常 proof 與 `/qa-test` 都從它選範圍，改動單元的公開行為或真機需求時改這裡。流程在 `teachbox100-testing` skill。

目標是保護老師與學生看得到的行為，而不是覆蓋率。每項測試都應從下表的公開行為出發；不測 Tailwind class、動畫實作或元件私有 state。

| 單元 | CI 自動保護的行為 | 真機 agent 驗收 |
| --- | --- | --- |
| 認識新臺幣 | 教學面額完整、不重複 | 無 |
| 金錢等值換算 | 選取面額能正確加總；可用硬幣設定在重整後保留 | 無 |
| 計算金錢價值 | 題目只用啟用面額、總額與四選一答案有效 | 無 |
| 付款 | 商品價格在設定上限與原始價格區間內 | 無 |
| 購物 | 商品架價格合法；桌機拖放與手機點選都能把商品放進購物車並加總 | 真手機長時間操作手感 |
| 找零 | 售價為正數、實付與找零正確 | 無 |
| 學習讀時鐘 | 12／24 小時出題範圍與時分作答判定；桌機滑鼠與手機 touch 拖曳分針跨 12 點會帶動時針 | 真手機觸控滑桿手感 |
| 翻牌配對 | 有效牌組可開始、可翻兩張並計一次翻牌 | 無 |
| 抽籤轉盤 | 名單可開始並有可操作的轉盤；停格演算法由單元測試保護 | 投影全螢幕下的轉動與結果可讀性 |
| 扭蛋機 | 名單可開始；挑球／打開／放回去／全部放回的狀態流轉由單元測試保護；手機紀錄預設收起，連抽 30 顆後最後一顆仍可從畫面點開 | 真機長時間抽取、球池堆疊與揭曉動畫的流暢度 |
| 一番賞 | 預設獎項內容與無效設定回復規則；輪播拖曳角度、放手吸附、循環索引；只接受由左往右的撕動；進度與獎項顯示範圍限制在有效區間；撕過門檻才揭曉，提早放手會回復；長文字依可用寬度縮放；撕票會觸發音訊節點，關閉音效後不觸發且重整保存 | 真實觸控旋轉選籤、票券轉為橫向的銜接、拖撕、3D 翻折與回彈手感、喇叭音質、獎項文字受底紙與翻折深度正確遮擋、全螢幕投影與獎項可讀性 |
| 大富翁 | 預設題庫可開始、規則與題庫解析均受單元測試保護 | 投影全螢幕、完整多人回合 |
| 計時器 | 開始、暫停、重設；倒數與考試時間規則 | 響鈴音效 |
| 噪音計 | 音量換算與區間；拒絕權限時有處理提示；合成音訊會帶動刻度升降，離頁後音軌停止，延遲授權在離頁後返回也會釋放音軌 | 真實麥克風授權、環境音量反應與瀏覽器指示燈熄滅 |
| 計分板 | 計分、步長、搶答排序與重連規則；兩個獨立學生瀏覽器可加入，單端離線重開後舊名次會對應新 peer 且不能重複按鈴；換房號後舊學生收到斷線提示並可用新房號加入；連線失敗會在 signaling relay 全部超時或載入／建立房間拋錯時送出不含房號及學生資料的 Sentry 診斷事件 | 教師與至少兩支真手機切飛航、恢復連線；校園網路下的實際連線；於 Sentry 遠端確認診斷事件 |
| 領地戰 | 棋盤格數可選自動（由題數決定）或小／中／大（12／20／35 格），行列都至少 3 並挑格子最接近正方形的排法；答對依難度暈開 1／2／3 格、答錯讓對方暈開 1 格並出局；先長中立格（離自己起點最近）、占完才吃對方（離對方起點最遠）；吃光判勝、題目出完比格數；每題倒數可選 3／4／5 秒，倒數時先顯示下一題幾分（「x 分題」）；倒數與場地大小跟著分享連結走，舊連結用 3 秒與自動；只收選擇與是非題；分出勝負時獲勝隊旗插進棋盤並貼上「x 獲勝！」，平手給中性卡 | 投影全螢幕時棋盤鋪滿、兩隊在觸控螢幕上同時搶答、暈開的換色在後排看得出先後；獲勝時旗子落地、紙屑鋪滿全螢幕、勝利音效 |
| 圈叉搶答 | 兩隊各自取得不同題目；答對後全場暫停並取得一次放棋或移棋權，答錯只讓該隊冷卻 3 秒；各隊三枚棋可先後進入任意空格，橫直斜三連線判勝；兩隊題庫都耗盡或老師手動結束時判和；難度只篩題、不改棋步，少於 6 題不能開始；連線獲勝時中央畫出獲勝隊的大圈或大叉並貼上「x 獲勝！」，和局照舊給中性卡 | 投影全螢幕時左右題目與中央棋盤在後排可讀；大型觸控螢幕上的雙隊近同時作答、即時鎖定、放棋與移棋手感；倒數、答對、答錯、落棋與勝利音效；獲勝時圈叉一筆一筆畫出、隊色紙屑從獲勝那一側連發、全螢幕下鋪滿整個螢幕 |
| 九九乘法練習 | 設定後可出第一題和四個選項；出題與結算規則；結算時分數從 0 跳到答對題數、貼上依得分的鼓勵紙膠帶（全對／好厲害／有進步／繼續加油），答對八成以上才撒紙屑、全對再加兩側紙屑砲，畫面不震動；手機作答紀錄不遮住答案與結算，內容超過一個畫面時不藏在頂列後面 | 跳分的滴答與勝利音效、全螢幕下紙屑鋪滿整個螢幕、減少動態效果時直接顯示分數 |
| 終極密碼 | `/ultimate-password` 可開始遊戲；先在兩站設定（題庫、難度）選好題目，自訂題庫還沒匯入時擋住開始，題庫與難度重整後還記得、可用分享連結帶走；進行中的密碼、範圍與答題階段重整後接著玩（關分頁才清空）；答題鈕按下後不變色，結果只由中央斜貼的紙膠帶呈現（答錯不搖）；猜中時鎖搖晃後炸開、揭曉密碼並貼上「破解成功！」；題目答對或答錯都先在畫面中央顯示結果與正解，答對後猜固定密碼，猜錯密碼先提示新範圍再換題，猜中揭曉密碼且可再玩一局 | 投影全螢幕下題目、數字範圍、答題切換與破關動畫的可讀性；減少動態效果時仍可辨識結果；破解時的滴答與開鎖音效、全螢幕下紙屑鋪滿整個螢幕 |
| 首頁入口 | 首頁只露分類與獨立單元，分類頁列出旗下所有單元；卡片依搜尋流量排序（抽籤、噪音計、翻牌配對、認識金錢、讀時鐘、大富翁在前）；舊網址 `/draw/lottery` 永久轉到 `/draw/gacha` | 無 |
| 頁面 SEO 文案 | 每頁與分類頁都有文案、標題與描述全站不重複、學習順序指向存在的頁、faq 不空 | 無 |
| 靜態頁版型（首頁、2 個分類頁、19 個單元的介紹頁與設定頁） | 桌機與手機兩個視窗寬度下，每頁的麵包屑、大標、說明段落、FAQ 與設定站排版逐像素不變；行高、間距、圓角、色票被改動時會整批變紅 | 無（畫面本身就是斷言；canvas 與物理動畫的畫面不在這批，仍靠上面各列的真機驗收） |
| 分享連結（有設定的 10 個單元） | 每個單元的設定來回編碼一致、壞連結不採用；短連結同內容同 id、到期延長、每 IP 次數限制；API 的 400／413／429／503 | 正式站建短連結、手機打開後設定帶入與到期日提示 |

靜態頁那一列由 `e2e/visual.spec.ts` 的 `toHaveScreenshot()` 保護，基準線在 `e2e/visual.spec.ts-snapshots/`（每頁兩張：desktop 與 mobile）。版型是故意改的就跑 `pnpm test:e2e e2e/visual.spec.ts --update-snapshots` 換掉基準線，並在 code review 看那批 PNG 的 diff。
